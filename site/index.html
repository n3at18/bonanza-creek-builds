What’s new

Since v0.5.1 · November 2026

01 / World

Lighting & materials

Warmer sunlight, new pack vegetation, scanned rock and ground textures, and consistent wood and metal finishes.

02 / Gameplay

Tree cutting

Three axes, cuts at the point of impact, falling trees and timber to collect and spend on upgrades.

03 / Equipment

Reworked tools

Replaced and tuned tool and cart assets. Clearer upgrade tiers and a rebuilt equipment menu.

04 / Automation

Rigs & carts

Better bucket, rope and chute motion. Carts stay tipped while unloading, with fewer routine alerts.

05 / Camp

Rebuilt camp

New sales and supply stalls, paths around the fire, and timber storage beside Sell Gold.

06 / River

Water & atmosphere

Clearer creek water, ripples, swimming fish and drifting mountain mist.

Real game captures. These pairs show individual November art passes, not matched v0.5.1 screenshots.

Also: cleaner panning feedback, improved loading and saving, and a fix for invisible camp collision blocking tree cuts.

First launch

Windows

Unzip and run the .exe. The unsigned build may trigger SmartScreen: More info → Run anyway.

macOS

Requires macOS 14+. Unzip, then right-click the app → Open. Ad-hoc signed, not notarized.

Linux

Unzip, then chmod +x the .x86_64 file and run it.
